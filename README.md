
# Student Management System (Oracle APEX)

Sistem i plotë për administrimin akademik të studentëve, i zhvilluar në mjedis web përmes **Oracle APEX** dhe **Oracle Database**.

## Përmbledhja e Projektit
Ky projekt u ndërtua për të menaxhuar dhe automatizuar proceset akademike bazë (studentët, lëndët, pedagogët, regjistrimet dhe notat). Ndërfaqja është dizajnuar si një aplikacion web interaktiv, ndërsa administrimi i të dhënave mbështetet në një arkitekturë të fuqizuar me bazë të dhënash relacionale.

## Karakteristikat Kryesore
* **Menaxhimi i Akademik:** Administrim i të dhënave për studentët, lëndët dhe stafin pedagogjik.
* **Integriteti i të Dhënave:** Struktura të dhënash me relacione të sakta (Primary Keys / Foreign Keys).
* **Automatizim:** Përdorim i *Oracle Triggers* për kontrollin e të dhënave dhe standardizimin e tyre.
* **Ndërfaqja Web:** Aplikacion ndërveprues i ndërtuar në Oracle APEX për gjenerimin e raporteve dhe menaxhimin në kohë reale.

## Teknologjitë e Përdorura
* **Platforma:** Oracle APEX
* **Baza e Të Dhënave:** Oracle Database, SQL, PL/SQL
* **Mjete:** Oracle SQL Developer
